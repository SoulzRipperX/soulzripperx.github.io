# Anime Adventures Trait Reroll

Unofficial static fan-made trait reroll simulator for Anime Adventures.

## Features

- Weighted trait rolls using the supplied trait percentages
- Superior, Nimble, and Range variants I / II / III with their exact stat bonuses
- Single, x10, and x100 rolls
- Separate auto-reroll mode that stops when a selected trait or variant appears
- Complete roll history with scrollable display
- Roll history and session statistics
- Responsive layout for desktop and mobile

## Run locally

Open `index.html` in a browser. No build step or server is required.

## GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
